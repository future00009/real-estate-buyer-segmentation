# Real Estate Buyer Segmentation

Machine Learning Based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence.

## Files required

Place these four files in the GitHub repository root:

- `app.py`
- `clients.csv`
- `properties.csv`
- `requirements.txt`

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The Streamlit application performs data cleaning, feature engineering, K-Means clustering, hierarchical validation, cluster profiling, and interactive dashboard analysis.
